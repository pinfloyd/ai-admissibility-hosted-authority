# Claims and Limits

Allowed claims:

- External admission authority
- Pre-execution admission decision
- Fail-closed enforcement model
- Enterprise-level architecture
- Enterprise-grade controlled proof
- GitHub Actions / CI/CD admission gate candidate

Forbidden claims:

- Finished Enterprise SaaS
- Compliance certification
- Guaranteed AI safety
- Production deployment
- Autonomous external execution
- Replacement for legal, security, or compliance review

Safe wording:

AI Admissibility provides a hosted external admission authority for selected high-impact automated execution.

Unsafe wording:

Do not claim absolute AI safety.

# Claims and Limits — historical/reference package

This repository contains historical Hosted Authority engineering material.

It is not the canonical installed runtime and not a live customer service.

## Current safe claims

- AI Admissibility is an external pre-execution admission-boundary model.
- The project has a canonical installed boundary used for controlled public demonstration and proof.
- The canonical public demonstration is https://ai-admissibility.com/canonical-pilot/.
- A real integration must fail closed when admission is denied, missing, invalid, stale, expired, or unverifiable.
- A signed ALLOW is an authority decision, not execution itself.

## Claims this repository must not make

- finished Enterprise SaaS;
- public customer production authority;
- public checkout or payment processing;
- automatic credential issuance;
- compliance certification;
- guaranteed AI safety;
- autonomous external execution;
- customer-specific no-bypass protection without deployment-specific evidence;
- replacement for legal, security, or compliance review.

## Historical wording

Earlier files may use terms such as Hosted Authority, SaaS roadmap, tenant layer, API key, or commercial path.

Those terms describe earlier design work and must not be interpreted as the current public product contract.

The website and GitHub repositories are showcase, documentation, proof, and demonstration surfaces.

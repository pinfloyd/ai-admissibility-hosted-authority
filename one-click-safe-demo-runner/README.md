# One-click Safe Demo Runner

Purpose:

Demonstrate the admission flow without external execution.

The demo runner must show:

1. Intent preparation.
2. Admission request construction.
3. Signed response handling.
4. Fail-closed behavior.
5. Owner approval requirement when applicable.
6. No external execution.

The demo must not send email, push GitHub, change a server, deploy a site, or call production customer systems.
